# Backend (Spring Boot)

Put your Spring Boot project here (generated from https://start.spring.io) so that
`pom.xml` and `src/` sit directly inside this `backend/` folder — that's what the
Dockerfile expects.

Recommended Spring Initializr dependencies for this stack:
- Spring Web
- Spring Security
- Spring Data JPA
- MySQL Driver
- Validation
- OAuth2 Client (for Google Login)

Once your project is here, `docker compose up --build` from the repo root will
build and run it automatically — nobody needs Java or Maven installed locally.
