# Frontend (React)

Put your React project here (created with `npx create-react-app .` or Vite) so
that `package.json` and `src/` sit directly inside this `frontend/` folder —
that's what the Dockerfile expects.

Suggested packages for this stack:
- react-router-dom
- axios
- tailwindcss
- chart.js + react-chartjs-2
- @testing-library/react

Once your project is here, `docker compose up --build` from the repo root will
build and serve it automatically at http://localhost:3000.
